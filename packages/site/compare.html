Engine portability

Every demo app reads its state from the same ?f parameter, through a serializer whose decode detects its own format tag. A link built here opens in any of them — React, Vue, Svelte, Angular, or no framework at all — and reproduces the identical result set.

Each link is a full page load into that app, which reads the state from ?f as it boots. Every demo
